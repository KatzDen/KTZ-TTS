# Говорилка (Piper TTS Talker)

Простая говорилка для Windows: озвучивает введённый текст локально,
без интернета, на движке [Piper TTS](https://github.com/OHF-Voice/piper1-gpl).

## Возможности

- 🔊 Озвучка текста одной кнопкой (синтез на CPU, работает офлайн)
- 🎙 Поддержка загружаемых голосовых моделей (.onnx + .onnx.json)
- ⬇ Скачивание готовых голосов прямо из приложения (русские и английские)
- 📁 Загрузка своих моделей через диалог выбора файла
- ⏩ Регулировка скорости речи
- 💾 Сохранение озвучки в WAV

## Установка и запуск

Требуется Python 3.9+.

```bash
pip install -r requirements.txt
python app.py
```

При первом запуске нажмите **«Скачать голос…»** и выберите голос —
модель скачается в папку `models` и появится в списке.

## Свои модели

Приложение принимает любые модели Piper: нужны два файла —
`голос.onnx` и `голос.onnx.json`. Их можно:

- загрузить через кнопку **«Загрузить из файла…»** (файлы скопируются в `models\`);
- или просто положить в папку `models\` вручную и нажать «↻».

Каталог готовых голосов: [rhasspy/piper-voices на HuggingFace](https://huggingface.co/rhasspy/piper-voices).

## Сборка в .exe

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name TtsTalker app.py
```

Готовый файл появится в `dist\TtsTalker.exe`.
